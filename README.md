Mayeutica es un tutor que usa Inteligencia Artificial.
Su propósito es inicialmente de uso personal para acompañar el proceso de escribir código sin dar la respuesta

La mayéutica es un método filosófico y pedagógico creado por Sócrates en la antigua Grecia, cuyo propósito es guiar al interlocutor para que descubra el conocimiento que ya lleva dentro a través de preguntas estratégicas
En base a esta misma filosofía, el tutor no será creado con IA Generativa para escribir código, pues esto no es consecuente con el fin del proyecto. 

Reglas del proyecto:
      - documentación de todo lo escrito
      - No se deben entregar directamente las respuestas al estudiante si no ha intentado realizar la tarea
      - El uso de IA para está limitado a la documentación y tests
